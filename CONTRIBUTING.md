# Contribuindo

1. Crie uma branch a partir da principal.
2. Faça alterações pequenas e focadas.
3. Nunca inclua `.env`, credenciais ou dados pessoais.
4. Execute `npm test` e `npm run test:e2e` quando o fluxo principal for afetado.
5. Explique no pull request o problema, a solução e a validação.

Commits em português ou inglês são aceitos, desde que claros e objetivos.
