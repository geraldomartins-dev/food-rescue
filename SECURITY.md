# Política de segurança

Este é um MVP de portfólio. Apenas a versão mais recente da branch principal recebe correções.

Não abra uma issue pública contendo credenciais, dados pessoais ou detalhes exploráveis. Use o **Private vulnerability reporting** do GitHub quando habilitado e inclua impacto, reprodução mínima e sugestão de correção, sempre removendo dados reais.

O projeto não deve ser considerado pronto para produção sem revisão de segurança, HTTPS, gestão externa de segredos, monitoramento, backups e controles operacionais de LGPD.
